This preview isn't running the app

You're seeing an empty shell because JavaScript is switched off here — which is what iOS does when it previews an HTML file (in Files, Mail, or Quick Look) instead of opening it as a real page. Everything you'd normally see is generated by the app itself, so nothing loads.

On iPhone, do this instead: put the file somewhere it can be opened as a web page and add it to your Home Screen. The quickest route is a free GitHub Pages link — ask Claude for the steps and it'll walk you through it. Once it's a Home Screen app it works fully and saves your data.

On a computer: save the file to your Desktop or Documents, then double-click it, or drag it onto a Chrome or Safari window.
