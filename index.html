This preview isn't running the app

You're seeing an empty shell because JavaScript is switched off here — which is what iOS does when it previews an HTML file (in Files, Mail, or Quick Look) instead of opening it as a real page. Everything you'd normally see is generated by the app itself, so nothing loads.

On iPhone, do this instead: put the file somewhere it can be opened as a web page and add it to your Home Screen. The quickest route is a free GitHub Pages link — ask Claude for the steps and it'll walk you through it. Once it's a Home Screen app it works fully and saves your data.

On a computer: save the file to your Desktop or Documents, then double-click it, or drag it onto a Chrome or Safari window.

Auto follows your phone or computer's setting.

Home sits in the middle of the phone's bottom bar and can't be moved — it is the one thing that should always be under the same thumb. Everything else rides on two sets you swipe between, sideways across the bar.

Browsers block most free price sources when the app runs as a downloaded file. A free API key fixes that — it takes about a minute and the key stays on your device.

Add your own, or remove ones you don't use. A category that's in use anywhere can't be deleted by accident.

When a description contains the text on the left, it's filed under the category on the right. First match wins.

Everything lives on your device / in a file you own — nothing is uploaded. Save writes a backup you can reopen with Load. That file is also how you sync your Mac and phone by hand: keep it in iCloud/Dropbox and open it from both.
